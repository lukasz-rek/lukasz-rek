## Few Cool Projects

**[rpi](https://github.com/lukasz-rek/rpi)** - Bare metal operating system for Raspberry Pi 4  
Custom OS built from scratch (and guidance from other bare metal projects) featuring simple terminal, user space execution, and SD card filesystem support. Written in C with ARM assembly.

**[riscv-cpu](https://github.com/lukasz-rek/riscv-cpu)** - At uni I've been taught many great things, but due to time constraints I feel I've never explored some of the stuff. This repo is an experiment in building up a riscv32ima core and originally it was meant to test out OoO execution but I'm on a very serious side-quest to get Linux running on it. 

Why?

I now have a risc32ima CPU that runs bare-metal and can run Zephyr or noMMU Linux and has raw perf comparable to modern microcontrollers.

**[array-multiplier-verilog](https://github.com/lukasz-rek/array-multiplier-verilog)** - Custom hardware multiplier in verilog that adapts to bit widths made as a tool for uni project. Could be improved but works!
