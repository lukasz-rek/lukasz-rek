## Few Cool Projects

**[riscv-cpu](https://github.com/lukasz-rek/riscv-cpu)** - A pipelined riscv32ima core that ended up booting noMMU Linux and Zephyr. Started as an experiment in out-of-order execution, but became a sidequest through RISC-V specs to first a machine mode RTOS then a user mode OS 

**[rpi](https://github.com/lukasz-rek/rpi)** - Bare metal operating system for Raspberry Pi 4  
Custom OS built from scratch (and sometimes inspirations from other bare metal projects) featuring simple terminal, user space execution, and SD card filesystem support. Written in C with ARM assembly.

**[array-multiplier-verilog](https://github.com/lukasz-rek/array-multiplier-verilog)** - Custom hardware multiplier in verilog that adapts to bit widths made as a tool for uni project. Could be improved but works and might help those few poor souls that like computer arithmetic like me!
